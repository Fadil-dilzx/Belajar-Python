# Belajar Python untuk Pemula 🚀

Repositori ini dibuat untuk mendokumentasikan proses belajar pemrograman Python tingkat dasar sekaligus sebagai pemenuhan **tugas sekolah**. Proyek ini mencakup konsep-konsep fundamental Python yang cocok untuk pemula.

## 📌 Fitur & Materi Pembelajaran
Di dalam repositori ini, terdapat beberapa materi dasar yang dipelajari, antara lain:
* **Variabel & Tipe Data**: Memahami String, Integer, Float, dan Boolean.
* **Percabangan (If-Else)**: Membuat keputusan logis dalam kode.
* **Perulangan (Loops)**: Menggunakan `for` dan `while` untuk eksekusi berulang.
* **Fungsi (Functions)**: Mengorganisasi kode agar bisa digunakan kembali.
* **Manipulasi List & Dictionary**: Mengelola struktur data sederhana.

## 🛠️ Prasyarat
Sebelum menjalankan kode di repositori ini, pastikan kamu sudah menginstal:
* Python (versi 3.8 atau yang lebih baru)
* Pip (pengelola paket Python)

## 🚀 Cara Menjalankan di Komputer Lokal

1. **Kloning repositori ini:**
   ```bash
   git clone https://github.com
   cd Belajar-Python
   ```

2. **(Opsional) Buat virtual environment:**
   ```bash
   python -m venv venv
   # Untuk Windows:
   venv\Scripts\activate
   # Untuk Mac/Linux:
   source venv/bin/activate
   ```

3. **Instal dependensi:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Jalankan salah satu file Python:**
   ```bash
   python nama_file.py
   ```
